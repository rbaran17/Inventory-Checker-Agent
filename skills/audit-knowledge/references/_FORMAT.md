<!-- Format guide for the audit knowledge skill. Not methodology content: the loader skips files whose
     names start with "_". Delete it or keep it once the real references are in place. -->

Each heading starts one searchable, citable section. Its id is `<file name>#<heading slug>`, for example
`test-counts#test-counts-in-both-directions`. Optional metadata lines go directly under the heading:

    # Test counts in both directions
    > refs: ISA 501.4(a)(iv); AU-C 501; AS 2510; FIRM-INV-3.2
    > topics: test_counts, procedures

    Body text the agents quote and cite...

Topics the agents filter on: planning, procedures, test_counts, cutoff, tag_control, condition,
sampling, documentation, alternative_procedures, third_party. Sections without topics are still found
by free-text search.
