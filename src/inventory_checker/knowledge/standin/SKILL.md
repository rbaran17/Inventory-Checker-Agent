# About this stand-in
> topics: documentation

This folder is a placeholder, not firm methodology and not the text of any standard. Each section is a
short paraphrased summary with references to the standards it relates to, so the agents have something
to search and cite during development. Replace it with the firm's audit knowledge skill by setting
AUDIT_KNOWLEDGE_SOURCE to `dir:<skill folder>` or `http:<search endpoint>`. Engagement teams must
follow the firm's methodology, not these summaries.
