# When attendance is impracticable
> refs: ISA 501.7; AU-C 501
> topics: alternative_procedures

If attending the count is impracticable, the auditor performs alternative procedures to obtain evidence
about existence and condition, for example inspecting documentation of the subsequent sale of specific
items acquired or purchased before the count. If sufficient evidence cannot be obtained, the auditor
considers the effect on the auditor's report.

# Documenting the inventory observation
> refs: AS 1215; AU-C 230; ISA 230
> topics: documentation

Document the procedures performed, the evidence obtained and conclusions reached in enough detail that
an experienced auditor with no previous connection to the engagement could understand them: who
observed, where and when; procedures observed and deviations; test counts with results and
differences; cutoff details; tag control; condition notes; and follow-up items. Photos and clips are
evidence and are retained with the workpapers.

# Documentation completion and retention
> refs: AS 1215; AU-C 230
> topics: documentation

For PCAOB audits, a complete and final set of documentation is assembled within 45 days after the report
release date and retained for seven years from that date. For AICPA (AU-C) audits, the final file is
assembled within 60 days after the report release date and retained for at least five years. Firm
policy may set longer periods.
