# Test counts in both directions
> refs: ISA 501.4(a)(iv); AU-C 501; AS 2510
> topics: test_counts, procedures

Test counts give evidence about the completeness and accuracy of the count records. Counting from the
floor to the count records (floor-to-sheet) addresses completeness: items present are recorded.
Counting from the records to the floor (sheet-to-floor) addresses existence: recorded items exist.
Perform both. Record for each test count the item, location, tag number, unit of measure, the client's
count and the auditor's count.

# Selecting items for test counts
> refs: AU-C 530; ISA 530; AS 2315
> topics: test_counts, sampling

Select test counts so that results can be used as audit evidence: include high-value items, items with
known counting difficulty, and a selection across zones. When sampling, the sample size and selection
method follow the firm's sampling methodology; items above a value threshold are often tested in full
and the remainder sampled.

# Differences found in test counts
> refs: AU-C 501; ISA 501; AS 2510
> topics: test_counts

When the auditor's count differs from the client's, have the client recount in the auditor's presence
and correct the count records where needed. Investigate the cause. If differences are frequent or
large, consider whether the count as a whole is reliable, extend test counts, and ask the client to
recount the area. Note each difference, its explanation and the corrected count. Tolerances for
reporting differences are set by the engagement team under firm methodology.
